1. What is jQuery and what are its core advantages? ▼

jQuery is a lightweight, "write less, do more" JavaScript library designed to simplify HTML DOM tree traversal, event handling, CSS animation, and Ajax interactions across various web browsers.

2. How do jQuery Selectors work under the hood? ▼

jQuery selectors allow you to select and manipulate HTML element(s). They utilize CSS selector syntax (e.g., tag names, classes, IDs, attributes) and integrate seamlessly with native document.querySelectorAll APIs.

3. What is the difference between $(document).ready() and window.onload? ▼

$(document).ready() triggers as soon as the DOM hierarchy is fully constructed, without waiting for images and stylesheets to load. In contrast, window.onload fires only after the entire page (including external assets) has finished loading.

4. How does event delegation work with jQuery .on()? ▼

Event delegation allows you to attach an event handler to a parent element, which listens for bubbled events triggered by current or future child elements matching a specified selector. This drastically improves memory efficiency and handles dynamically added DOM elements.

5. What are the key built-in animation effects in jQuery? ▼

jQuery provides built-in visual effect methods including .show()/.hide(), .fadeIn()/.fadeOut(), .slideDown()/.slideUp(), and the versatile .animate() method for custom property transitions.
