# HTML Practice & Exercises 🌐

This branch contains HTML exercises, semantic markup, and hands-on assignments completed as part of the **BridgeLabz 3-Year Training Program**.

---

## 📁 Directory Overview

The [`html-practice/`](file:///c:/Users/shrey/Downloads/BridgeLabz-Training-3Y/html-practice) folder includes structured exercises:

### `gcr-codebase/`
Topic-by-topic modules with progressive exercises and assignments:

| Module | Description | Key Focus |
| :--- | :--- | :--- |
| **`html-basics`** | Core HTML Syntax (Q1 – Q20) | Document structure, headings (`<h1>`-`<h6>`), paragraphs, links |
| **`block-inline-elements`** | Display Types (Q1 – Q15) | Block (`<div>`, `<p>`) vs Inline (`<span>`, `<a>`, `<strong>`) |
| **`iframes`** | Inline Frames (Q1 – Q20) | Embedding external content, videos, documents, targets |
| **`forms`** | Web Forms | Input controls, types, labels, validation, form submission |
| **`tables`** | Tabular Data | `<table>`, `<tr>`, `<th>`, `<td>`, `colspan`, `rowspan` |
| **`lists`** | Ordered & Unordered Lists | `<ul>`, `<ol>`, `<li>`, nested lists, description lists (`<dl>`) |
| **`semantic-html`** | Modern Semantic Markup | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` |
| **`entities-uri`** | HTML Entities & URLs | Special character entities (`&copy;`, `&amp;`), relative/absolute paths |
| **`responsive-html`** | Viewport & Meta Tags | Responsive meta tags, picture element, responsive images |
| **`introduction-to-web`** | Web Fundamentals | Web architecture basics & ASSIGNMENT 1 |

### `practice-codebase/`
Independent problem statements, lab practice, and assignments.

---

## 🚀 Getting Started

To view and practice with these files:

```bash
# Switch to this branch
git checkout html-practice

# Navigate to any topic
cd html-practice/gcr-codebase/html-basics
```

Open any `.html` file directly in a web browser or run with VS Code's Live Server extension.
