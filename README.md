# CSS Practice & Exercises 🎨

This branch contains CSS styling, layout modules, and responsive design exercises completed as part of the **BridgeLabz 3-Year Training Program**.

---

## 📁 Directory Overview

The [`css-practice/`](file:///c:/Users/shrey/Downloads/BridgeLabz-Training-3Y/css-practice) folder includes structured exercises:

### `gcr-codebase/`
Modular CSS topic folders with progressive hands-on questions:

| Module | Description | Key Focus |
| :--- | :--- | :--- |
| **`css-basics`** | Core styling syntax (Q1 – Q10) | Colors, fonts, borders, margins, selectors |
| **`box-model`** | Box Model mechanics (Q1 – Q10) | Content, padding, border, margin, `box-sizing` |
| **`flexbox`** | Flexible Box Layout (Q1 – Q10) | Align items, justify content, flex-direction, flex-wrap |
| **`css-grid`** | 2D Grid Layout System | Grid templates, areas, gaps, fractional units (`fr`) |
| **`responsive-design`** | Responsive Web Design (Q1 – Q10) | Fluid grids, responsive images, viewport meta |
| **`media-queries`** | Media Queries | Breakpoints for mobile, tablet, and desktop views |
| **`navigation-bar`** | Navigation Components | Horizontal nav, dropdown menus, responsive hamburger bars |
| **`positioning`** | Positioning Schemes | `static`, `relative`, `absolute`, `fixed`, `sticky`, z-index |
| **`pseudo-classes`** | Interactive Pseudo-selectors (Q1 – Q10) | `:hover`, `:focus`, `:active`, `:nth-child`, `:before`, `:after` |
| **`animations` & `transitions`** | Motion Effects | CSS transitions, keyframe animations, transforms |
| **`typography`** | Web Typography | Font families, weights, line-height, Google Fonts integration |
| **`colors-backgrounds`** | Visual Aesthetics | Gradients, background images, opacity, hex/rgb/hsl colors |
| **`filters` & `tooltips`** | Visual Utilities | Drop shadows, blur, custom hover tooltips |

### `practice-codebase/`
Independent assignment challenges and practice implementations.

---

## 🚀 Getting Started

To view and run the CSS exercises:

```bash
# Switch to this branch
git checkout css-practice

# Navigate to any topic
cd css-practice/gcr-codebase/box-model
```

Open the `.html` files in any web browser to see the styled components and inspect them using DevTools.
