# JavaScript Practice & Assignments ⚡

This branch contains hands-on JavaScript exercises, tasks, and project-based assignments completed as part of the **BridgeLabz 3-Year Training Program**.

---

## 📁 Directory Overview

The [`javascript-practice/`](file:///c:/Users/shrey/Downloads/BridgeLabz-Training-3Y/javascript-practice) folder covers fundamental to advanced modern JavaScript topics:

| Module | Description | Key Topics |
| :--- | :--- | :--- |
| **`JS Intro`** | Getting Started | Variables (`var`, `let`, `const`), Data types, Console output |
| **`JS Operator`** | Operators & Expressions | Arithmetic, Logical, Comparison, Ternary, Assignment |
| **`JS Function`** | Functions | Function declarations, Function expressions, Arrow functions, Callbacks |
| **`JS ES Feature`** | Modern ES6+ Features | Destructuring, Spread/Rest operators, Template literals, Default params |
| **`JS-Classes`** | Object-Oriented JS | ES6 Classes, Constructors, Methods, Getters & Setters |
| **`OOPS with JS`** | OOP Principles | Inheritance, Encapsulation, Polymorphism, Real-world modeling tasks |
| **`JS Dom`** | DOM Manipulation | Event handling, Querying elements, Dynamic rendering, Form interactions |
| **`Asyc Programming with JS`** | Asynchronous JS | Promises, `async/await`, Fetch API, Timers (`setTimeout`, `setInterval`) |

---

## 🚀 Getting Started

To explore or run the JavaScript files:

```bash
# Switch to this branch
git checkout javascript-practice

# Navigate into the javascript folder
cd javascript-practice

# Run any script with Node.js
node "OOPS with JS/Q1. Student Result Processing.js"
```

For HTML-based DOM / Class exercises:
Open the respective `.html` files in any modern web browser or with Live Server.
