## 🧭 How to Navigate the Branches

### 1. Clone the Repository
```bash
git clone https://github.com/Shreyash-max/BridgeLabz-Training-3Y.git
cd BridgeLabz-Training-3Y
```

### 2. View All Available Branches
```bash
git branch -a
```

### 3. Switch to a Specific Technology Branch
```bash
# HTML Practice
git checkout html-practice

# CSS Practice
git checkout css-practice

# Bootstrap Practice
git checkout bootstrap-practice

# JavaScript Practice
git checkout javascript-practice

# Return to Main
git checkout main
```

## 📚 Module Overview

### 🌐 1. HTML Practice (`html-practice`)
Focuses on standard web structures, tags, and accessibility:
- **HTML Basics & Introduction to Web**: Document anatomy, headings, paragraphs, links, and ASSIGNMENT 1.
- **Block & Inline Elements**: Understanding block formatting contexts and inline element behavior.
- **Forms & Inputs**: Validation, input types, labels, fieldsets, and submissions.
- **Tables & Lists**: Data tables with spanning headers, ordered/unordered/description lists.
- **Semantic HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **Iframes & Entities**: Embedding external documents and character entities.

### 🎨 2. CSS Practice (`css-practice`)
Focuses on styling, page layout techniques, and modern responsive design:
- **CSS Basics**: Selectors, specificity, colors, borders, and typography.
- **Box Model**: Margin collapsing, padding, content box vs border box.
- **Flexbox & Grid**: 1D and 2D responsive layout mechanics.
- **Responsive Design & Media Queries**: Fluid layouts adapting to mobile, tablet, and desktop screens.
- **Pseudo-classes & Selectors**: Dynamic states (`:hover`, `:focus`, `:nth-child`).
- **Animations & Transitions**: Smooth transformations and keyframe animations.

### 🚀 3. Bootstrap Practice (`bootstrap-practice`)
Focuses on rapid UI development using the Bootstrap 5 framework:
- **Grid System**: Breakpoints (`sm`, `md`, `lg`, `xl`), row/col divisions, and offsets.
- **Components**: Navbars, alerts, badges, modals, carousels, panels, and progress bars.
- **Utility Classes**: Spacing (`m-*`, `p-*`), typography, flex utilities, and themes.

### ⚡ 4. JavaScript Practice (`javascript-practice`)
Focuses on vanilla JavaScript, modern ECMAScript standards, and programmatic problem-solving:
- **Language Fundamentals**: Variables (`let`, `const`), operators, conditional logic, and loops.
- **Functions & ES6+**: Arrow functions, destructuring, rest/spread operators, and template literals.
- **OOP & Classes**: Class syntax, constructor methods, getters/setters, and inheritance.
- **DOM Manipulation**: Event listeners, element querying, dynamic rendering, and interactive UI logic.
- **Asynchronous Programming**: Promises, `async`/`await`, fetch requests, and the JavaScript event loop.
