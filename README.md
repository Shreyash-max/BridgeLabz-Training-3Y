# Bootstrap Practice & Exercises 🎨

This branch contains responsive UI practice files, components, and layout exercises built with **Bootstrap** as part of the **BridgeLabz 3-Year Training Program**.

---

## 📁 Directory Overview

The [`bootstrap-practice/`](file:///c:/Users/shrey/Downloads/BridgeLabz-Training-3Y/bootstrap-practice) folder includes component practices and codebase templates:

### `gcr-codebase/`
Contains modular topic-wise exercises:

| Module | Description |
| :--- | :--- |
| **`alerts`** | Contextual alert components and dismissal events |
| **`badges-labels`** | Visual indicators, count badges, and tags |
| **`bootstrap-basics`** | Core setup, typography, and container layouts (Q1 – Q10) |
| **`bootstrap-components`** | Navbars, buttons, lists, cards, and modal dialogs |
| **`carousel`** | Interactive image sliders with controls and indicators |
| **`grid-system`** | Responsive 12-column grid layout, column wrapping, offsets |
| **`pagination`** | Page navigation controls and states |
| **`panels`** | Panel and card groupings for structured content display |
| **`progress-bar`** | Animated and striped dynamic progress meters |
| **`themes`** | Color utility classes, theming, and styling overrides |

### `practice-codebase/`
Independent sandbox exercises and assignments applying Bootstrap concepts.

---

## 🚀 Getting Started

To view and practice with these files:

```bash
# Switch to this branch
git checkout bootstrap-practice

# Navigate to the exercises
cd bootstrap-practice/gcr-codebase/bootstrap-basics
```

Open any `.html` file with your web browser or VS Code's Live Server extension to see responsive rendering in action.
