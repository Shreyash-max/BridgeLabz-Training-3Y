Team Members Directory

Hierarchical Corporate Directory demonstrating jQuery DOM Traversals

🔍 Traversing Rules in Action:

  • 1. Click Manager Card: Highlights all direct reports under that manager.
  • 2. Hover Employee Card: Reveals contact info using jQuery .next() traversal.
  • 3. Click Department Header: Alters background of all children in that department using .children().
  • 4. Click Employee Card: Highlights their sibling coworkers using .siblings().
  • 5. Click "Collapse/Expand": Toggles department visibility using .parent() and .find().
