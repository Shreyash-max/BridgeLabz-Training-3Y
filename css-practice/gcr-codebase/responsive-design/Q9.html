Responsive Design Principles

Fluid Layouts

Fluid layouts use flexible sizes so content can adapt to different screen widths. 

width: 100%;

Flexible Media

Images and media should resize according to the available screen space. 

img {
    max-width: 100%;
}

Breakpoints

Breakpoints change the layout when the screen reaches specific widths. 

@media (max-width: 600px) {
    ...
}
